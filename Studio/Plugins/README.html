Studio/Plugins

Simgenics-internal shared .xplugin packages reused across multiple training products (e.g. IndustrialEquipment, HMIPanels, ModbusProfiles, SimgenicsTheme, ScoringRubrics). The Studio tier sits between /Engine/ and /Projects/; Studio plugins may depend on Engine plugins, and Project plugins may depend on Studio plugins. Studio plugins are promoted up from /Projects/<Product>/Plugins/ through the deliberate hoisting workflow when a plugin is reused by a second product. This directory currently holds no plugins — it is a placeholder for shared Studio-tier plugins.
