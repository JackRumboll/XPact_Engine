Studio/Content

Simgenics-internal shared content (meshes, materials, textures, audio, animation, generic HMI assets) reused across multiple training products. The Studio tier sits between /Engine/ (universal engine content) and /Projects/<Product>/Content/ (per-product assets). Assets are promoted into this tier from a /Projects/<Product>/Content/ via the deliberate hoisting workflow when an asset is used by a second product. This directory currently holds no content — it is a placeholder for shared Studio-tier assets.
