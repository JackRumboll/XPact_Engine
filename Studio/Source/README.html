Studio/Source

Simgenics-internal shared C++/C# modules reused across multiple training products. The Studio tier sits between /Engine/ (universal XPact engine code) and /Projects/ (per-product training applications). Code is promoted into this tier from a /Projects/<Product>/ via the deliberate hoisting workflow when a behavior is used by a second product; code promoted out of this tier into /Engine/ happens only when something here proves universally applicable. This directory currently holds no modules — it is a placeholder for shared Studio-tier source.
