Engine / Build

Engine-tier build infrastructure — platform-specific build files, batch / shell entry points that invoke XBT, MSBuild props/targets for the C# tooling, SharedPCH definitions, target/module template fragments, and any other engine-level build assets that XBT consumes or emits. Per-platform subdirectories (Win64, Linux, Android) hold platform-specific toolchain configuration. Generated Binaries and Intermediate trees produced by XBT live elsewhere in the repo and are gitignored.
