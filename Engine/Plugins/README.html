Engine / Plugins

Engine-tier plugins — self-contained, depend only on other Engine-tier code, and ship as part of every engine release with versions equal to the engine's. Includes the universal industrial-protocol stack (XModbus and its hooks for OPC-UA / IEC 61850 / custom), Layer 14 VR plugins (XOpenXR, XVR), and other engine-universal capabilities authored as plugins rather than core modules. Each plugin carries an .xplugin descriptor declaring Tier = Engine, per-target / per-platform enablement, and module list. Studio and Project plugins may depend on Engine plugins; Engine plugins may not depend on Studio or Project code.
