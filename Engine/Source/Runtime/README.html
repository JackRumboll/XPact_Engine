Engine / Source / Runtime

Runtime modules ship in all build configurations (Debug, DebugGame, Development, Test, Shipping) and are present in the Editor, Game, and Server targets. Houses the foundational Engine-tier runtime systems — XCore, XCoreXObject, XLog, XApplicationCore, XSerialization, XRHI, XRenderer, XSlate, XUMG, XPhysics, XAudio, XNetworking, XAnimation, gameplay foundations (XWorld / XActor / XComponent / XGameMode / XGameInstance / XSubsystems), and every other system that runs on the trainee, instructor, or server target. Module subdirectories follow the Unreal-mirror Public/Private convention and declare Tier = Engine in their .Build.cs.
