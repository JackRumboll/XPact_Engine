Engine / Source / Developer

Developer-tier modules — available in Debug, DebugGame, Development, and Test configurations but stripped from Shipping. Houses tooling and instrumentation that supports authoring and diagnostics but is not part of the trainee runtime: XTrace profiling/instrumentation backend pieces, XInsights ingestion, XDerivedDataCache developer-facing surfaces, XLiveCoding host-side machinery, XCrashReportClient developer paths, asset cookers and validators that ride along during PIE, and similar developer-only utilities. Modules follow the Unreal-mirror Public/Private convention.
