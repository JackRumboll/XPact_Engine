Engine / Source / Programs

Standalone executables built independently of the engine targets. Houses the Layer 0 Build & Tooling programs — XBT (C# build tool), XHT (C# header tool / reflection extractor), XIL2CPP (C# transpiler), XAutomationTool (release pipeline, code signing, MDM packaging, symbol upload), XShaderCompileWorker, XInterchangeWorker, XPak, XCrashReportClient, XAutoUpdate, XBuildPatchTool, XBuildAccelerator (post-MVP), and the XDerivedDataBuildWorker. Each program ships as its own executable and is invoked by XBT or by the developer/release pipeline; programs do not depend on engine runtime modules they cannot statically link.
