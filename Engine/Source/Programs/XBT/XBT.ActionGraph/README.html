XBT.ActionGraph

The action-graph and execution subsystem of the XPact Build Tool. Owns the in-memory build DAG (ActionGraph), the per-output content-hash cache (ActionHistory), and the local parallel executor (ParallelExecutor).

Per /Documents/XBT.html Rev 4 Sections 5 (Action Graph), 6 (Executor), 15 (Caching), and Toolchain Contract Rev 13 Section 10.3 ("Action Graph") + Section 13 ("Exit Code Surface").

Public surface (Phase 1.2):

  • XActionType — enum locking the action-type slots per Contract Section 10.3. Slots 0–8 + 13 + 16 are live; slots 9–15 are Phase 2 reservations (XPactBuildAccelerator, XLiveCoding); slot 17 (formerly RunPostBuildAction) is retired and never reused. Slot ordering is the cache-key input that ActionHistory.CurrentVersion hashes.
  • IExternalAction + ExternalAction — the per-action contract (Section 5.2). Each action declares its prerequisites and produces, the command line to run, the CommandVersion hash (auto-derived from the field set), the remote-cache key components, and the provenance fields. Implementations are immutable records; sorting + determinism rules enforced at construction.
  • LinkedAction — an IExternalAction wrapped with the resolved PrerequisiteActions back-links for topological sort and scheduling.
  • ActionGraph — the DAG. Builds the FileItem → LinkedAction producer map, validates conflicts, detects cycles (Kahn's algorithm with deterministic tiebreak by CommandVersion), and emits a sorted list suitable for executor dispatch. Throws ActionGraphConflictException (exit 80) on duplicate-producer output and ActionGraphCycleException (exit 80) on cycle detection. Supports GetActionsForSubset for XLiveCoding's compile-only pass (Section 16.6).
  • ActionHistory — per-output content-hash cache (Section 15.2). Partitioned by hash-prefix bucket for low-contention parallel writes; persisted atomically (temp + rename per Section 6.4). CurrentVersion is auto-derived from a BLAKE3 hash of the IExternalAction property set (footgun #8 preempt).
  • ParallelExecutor — local-only worker pool sized to Environment.ProcessorCount. Honors cancellation (Ctrl-C with 5-second grace per Section 6.4); writes outputs through temp-file + atomic-rename so a killed action never leaves a torn output; respects bCanExecuteRemotely as a hint (Phase 1: ignored; Phase 2: consumed by XPactBuildAccelerator).

No engine-runtime imports. Pure tooling code; only references XBT.Core (primitives) and XBT.Manifest (shared enums + ContractVersion).
