XBT.Tests

xUnit test harness for XBT's Phase 1 modules per /Documents/XBT.html Rev 4 Section 22. Owned by Subagent B.

How to run

From the repo root:

dotnet test Engine/Source/Programs/XBT/XBT.Tests/XBT.Tests.csproj

The test project depends on XBT.Core and XBT.Manifest via ProjectReference. Building the solution (dotnet build Engine/Source/Programs/XBT/XBT.sln) builds the test project and its dependencies in one shot.

Why no fixtures yet

Phase 1 ships unit tests only -- the integration / reproducibility / tier-enforcement / IBuildHook fixture suites in XBT.html Sections 22.2 through 22.7 require ModuleRules, ActionGraph, and WriteManifestAction implementations that arrive in Phases 1.1 -- 1.3. The xUnit harness here is the seed: future fixtures slot into XBT.Tests/Fixtures/ as their owning systems land.
