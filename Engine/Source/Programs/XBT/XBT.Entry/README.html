XBT.Entry

The XBT executable. Owns Main, the CLI parser, the mode dispatcher, and the built-in modes. Implements UnrealBuildTool's IToolMode<T> pattern with C# 12 static-abstract members.

Phase 1 modes (this commit):

  • Help — lists all registered modes. Always works even if other modes fail; exit 0.
  • Version — prints XBT version, .NET runtime version, BLAKE3 library version, and ContractVersion.Current; exit 0.
  • Build — stub. Prints "BuildMode is not yet implemented" and exits 1. Phase 1.2 work lands the action graph, toolchain abstraction, descriptor evaluator, and the actual build pipeline.
  • QueryTargets — emits a hard-coded JSON document listing the three default targets (Editor / Game / Server) and the five build configurations from XBT.Manifest.Enums. Useful smoke test for the manifest types.

Cancellation is honored via Console.CancelKeyPress: Ctrl-C signals a CancellationTokenSource passed to every mode's ExecuteAsync entry. Exit code 130 on cancel per Toolchain Contract Rev 13 Section 13 (SIGINT convention).

All Console.Out / Console.Error writes go through Simgenics.XPact.XBT.Core.Logger so the streaming JSON channel hook (/Documents/XBT.html Section 21.2) can mirror every record into the IDE-subscriber stream at Phase 1.1.
