XBT.Discovery

Plugin and module discovery layer of the XPact Build Tool. Walks /Engine/, /Studio/, and /Projects/ trees for .xplugin and .Build.toml files, applies shadow precedence per Toolchain Contract Rev 13 Section 9.4 (Project shadows Studio shadows Engine for same plugin name), and records all observed plugin descriptors so a hot-rebuild does not spuriously rebuild when a non-shadowed plugin elsewhere is touched (the Rev 2 audit finding #8 fix in /Documents/XBT.html Section 17.2).

Public surface (Phase 1.2):

  • PluginEnumerator — walks the three plugin roots (/Engine/Plugins/, /Studio/Plugins/, /Projects/<P>/Plugins/) for *.xplugin files. Returns a PluginCatalog.
  • ModuleEnumerator — walks every tier's Source/ tree and each plugin's Source/ tree for *.Build.toml files. Returns a ModuleCatalog.
  • PluginCatalog / ModuleCatalog — deduplicated, tier-tagged result sets. The plugin catalog records ALL observed descriptors of each name so cache invalidation tracks shadow changes correctly.
  • DiscoveryDiagnostics — structured diagnostics via the Logger when a plugin/module is invalid or fails tier validation.

No engine-runtime imports. Pure tooling code; references XBT.Core, XBT.Manifest, XBT.Configuration.
