# `.xproject` Schema

The XPact project descriptor inherits the `.uproject` schema from Unreal Engine, with renames + an optional `XPactScripting` plugin entry for C# game-script projects.

## File Location & Naming

- Per-project file: `<ProjectRoot>/<ProjectName>.xproject` (e.g., `MyFactory.xproject`).
- Mirrors Unreal's `.uproject` location/naming convention.

## Schema (JSON)

```json
{
  "FileVersion": 3,
  "EngineAssociation": "5.9.0-xpact",
  "Category": "IndustrialTraining",
  "Description": "Factory floor training scenario",

  "Modules": [
    {
      "Name": "MyFactory",
      "Type": "Runtime",
      "LoadingPhase": "Default",
      "AdditionalDependencies": ["XEngine", "XPactScripting"]
    }
  ],

  "Plugins": [
    {
      "Name": "XPactScripting",
      "Enabled": true,
      "MarketplaceURL": null,
      "Settings": {
        "ScriptingProjects": [
          {
            "ProjectPath": "Scripts/MyFactoryScripts.csproj",
            "Modules": ["XEngine", "XSlate", "XPropertyEditor"]
          }
        ]
      }
    },
    {
      "Name": "Datasmith",
      "Enabled": true
    },
    {
      "Name": "LidarPointCloud",
      "Enabled": true
    },
    {
      "Name": "VariantManager",
      "Enabled": true
    }
  ],

  "TargetPlatforms": ["Win64"],
  "EpicSampleNameHash": null
}
```

## XPactScripting Plugin Entry

The `XPactScripting` plugin is XPact-specific (not in Unreal). Its `Settings.ScriptingProjects` array declares C# game-script projects to compile alongside the C++ project.

| Field | Type | Meaning |
|---|---|---|
| `ProjectPath` | string | Relative path from `.xproject` directory to the C# `.csproj` |
| `Modules` | string[] | List of XPact module names whose `bindings.json` the C# project consumes |

Per decision #53, XBT processes this list to:
1. Emit `xpact.modules.props` at the `.csproj` directory.
2. Emit a `Directory.Build.targets` that adds each `bindings.json` to `<AdditionalFiles>`.
3. The Roslyn source generator `XPactBindingGen` then sees the `bindings.json` items during C# compile.

## Path Conventions

- All paths relative to the `.xproject` directory.
- Forward slashes preferred (Windows accepts both; tooling normalizes).
- `..` allowed for going outside project root (rare; only for shared script libraries).

## Versioning

`FileVersion: 3` matches Unreal 5.9.0 `.uproject` shape. Bumps require migration logic in XBT.

## Sample MVP-1 `.xproject`

Phase 5 industrial-training sample project (`MyFactory/MyFactory.xproject`) ships with the schema above, with one `Modules` entry, `XPactScripting` plus enterprise plugins enabled, and `TargetPlatforms: ["Win64"]`.

## Interaction with `xpact.modules.json`

The two files serve distinct purposes:

| File | Owned by | Purpose |
|---|---|---|
| `<Project>.xproject` | Project author | Declares modules + plugins + scripting projects at the project level |
| `xpact.modules.json` (in C# project directory) | XBT (auto-emitted from .xproject's XPactScripting settings) | Concrete list of `bindings.json` paths for one specific `.csproj` |

C# project authors only edit `.xproject`. `xpact.modules.json` is regenerated by XBT on every `-genproject` invocation.
