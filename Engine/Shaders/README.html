Engine / Shaders

Engine-tier shader source consumed by XShaderCompiler and XShaderCompileWorker. Houses HLSL / cross-compiled shader sources for XRenderer, XRenderCore, XSlateRHIRenderer, XMaterials, XGI, XLOD, XVirtualTexturing, XHLOD, XVFX, XDigitalHuman, XFacialRig, and every other rendering system in /Engine/Source/Runtime/. Vulkan is the only target backend (per Section 2 Render API row); the XRHI abstraction layer keeps a second backend insertable under duress. Compiled-shader caches and Pipeline State Object caches are emitted by XShaderPipelineCache and live in the gitignored Intermediate tree, not here.
