Engine / Content

Engine-tier content — .xasset files, default materials, primitive meshes, fallback textures, editor icons, default sound cues, and other content shipped as part of the engine itself. Mounted at the virtual root /Engine/Content/... per the cross-tier asset reference convention in Section 2. Reused by every Simgenics training product. Content authored at the Studio or Project tier lives under those tiers, not here; hoisting Studio or Project assets into Engine is a deliberate design action with cross-system review.
