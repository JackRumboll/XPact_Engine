Engine / Config

Engine-tier .xconfig base configuration. First layer in the Engine → Project → Platform → User overlay order defined by the configuration system. Houses base CVar defaults, default XDeveloperSettings values, default device profiles, default platform key bindings, and the engine-wide defaults for every system that exposes configuration. Project- and Platform-tier overlays may override anything declared here, but the engine-tier file is the source of truth for unset keys.
